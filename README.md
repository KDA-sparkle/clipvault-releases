# ClipVault : téléchargements

Versions publiques de **ClipVault** (Windows et Linux). Ce dépôt ne contient pas de code : seulement les installateurs, dans les [Releases](https://github.com/KDA-sparkle/clipvault-releases/releases), et les fichiers que l'application lit pour se mettre à jour toute seule.

- **Télécharger la dernière version** : [Releases, dernière version](https://github.com/KDA-sparkle/clipvault-releases/releases/latest)
- **Site** : https://valyrix.eu

| Système | Fichier |
|---|---|
| Windows 10 et 11 | `ClipVault-Partage-Setup-<version>.exe` |
| Ubuntu, Debian, Mint | `clipvault-partage_<version>_amd64.deb` |
| Arch, Manjaro | `clipvault-partage-<version>-x86_64.pacman` |
| Autres distributions | `ClipVault-Partage-<version>-x86_64.AppImage` |
